# Deloitte Australia Data Analytics Virtual Experience Program

## Overview

This repository contains my work completed as part of the Deloitte Australia Data Analytics Virtual Experience Program on Forage.

The program focused on analyzing operational and workforce data to support business decision-making through data visualization and analytical problem-solving.

---

## Task 1: Telemetry Data Analysis

### Objective
Analyze machine telemetry data collected from multiple manufacturing facilities and identify locations with the highest machine downtime.

### Tools Used
- Tableau

### Work Completed
- Imported and analyzed telemetry data from multiple factories.
- Created a calculated field to measure machine downtime.
- Developed interactive Tableau dashboards to compare downtime across factories and device types.
- Identified the factory and machine categories contributing most to operational downtime.

### Skills Demonstrated
- Data Visualization
- Tableau Dashboard Development
- Operational Data Analysis
- Business Problem Solving

---

## Task 2: Forensic Technology Analysis

### Objective
Assist in an investigation into potential gender pay inequality using employee compensation data.

### Work Completed
- Analyzed equality score data across job roles and factories.
- Classified records into Fair, Unfair, and Highly Discriminative categories based on predefined thresholds.
- Applied logical rules to support workforce equality assessment.

### Skills Demonstrated
- Data Analysis
- Excel
- Data Classification
- Analytical Reasoning
